# b0dy-coach

App coach / logbook của B0DY Studio — **https://checkin.b0dy.studio** (PWA, GitHub Pages từ `main`). Từ 13/10/2026 (trước đó ở demo.b0dy.studio; demo nay là kiosk cũ `quangvinh376/b0dy-checkin`, có màn chuyển cho máy coach còn biểu tượng cũ).
