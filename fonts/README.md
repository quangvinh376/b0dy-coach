# Font

App dùng **SVN-Switzer** weight 500 (Medium) làm font chữ chính. Thả **một** trong các file sau vào thư mục này, đặt đúng tên:

- `SVN-Switzer-Medium.ttf` hoặc `SVN-Switzer-Medium.otf` (file anh có sẵn, dùng được ngay)
- `SVN-Switzer-Medium.woff2` / `.woff` (nhỏ hơn, nếu sau này có)

Trình duyệt tự chọn file đầu tiên tồn tại theo thứ tự woff2 → woff → ttf → otf. Chưa có file thì app lùi về Switzer (Fontshare) rồi font hệ thống. Số và nhãn dùng JetBrains Mono (Google Fonts).
